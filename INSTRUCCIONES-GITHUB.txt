PÁGINA WEB - DISEÑO APROBADO

1. Abre tu repositorio GitHub.
2. Add file > Upload files.
3. Sube index.html, manifest.webmanifest y TODA la carpeta assets (arrastrándola completa).
4. Revisa las rutas assets/logo.png, assets/modelo.jpg, assets/satipo_plaza.jpg, assets/satipo_noche.jpg, assets/satipo_rio.jpg.
5. Commit changes. Espera a GitHub Pages.
6. Recarga tu página con Ctrl+F5.

El reproductor y el clima usan internet. El enlace de Facebook abre Facebook genérico hasta que proporciones la URL de la radio.
La maqueta suministrada es referencia: la portada web adapta sus elementos a pantallas y usa fecha/hora/clima reales.
